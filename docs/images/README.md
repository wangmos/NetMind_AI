# 截图目录

根 README 会自动引用这四张图，把文件放进来即可显示（缺图只会显示占位，不影响其他内容）：

| 文件名 | 建议内容 |
| --- | --- |
| `overview.png` | 实时概览页，能看到流量表与统计 |
| `traffic.png` | 流量探索页，左侧列表 + 右侧证据检查器 |
| `ai.png` | AI 分析页，一轮带 `[#序号]` 引用的回答 |
| `script.png` | 脚本页三栏：脚本库 / 编辑器 / 采集钩子与运行结果 |

建议宽度 1600–1920 px，PNG。截图前请确认画面中没有真实账号、令牌或个人信息。
